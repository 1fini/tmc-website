# Consignes Codex — site Tennis Mentors Club

## Objectif
Construire et maintenir le site vitrine officiel de Tennis Mentors Club avec Astro, en privilégiant un rendu premium, rapide, accessible et simple à déployer sur GitHub Pages.

## Identité visuelle
- Utiliser exclusivement le logo officiel fourni dans `public/assets/images/tmc-logo.png`.
- Ne jamais redessiner, modifier, recadrer ou recolorer le logo.
- Couleurs principales : bleu marine, bleu vif, vert lime, blanc et gris clairs.
- Baseline : « Accompagner · Soutenir · Faire grandir ».
- Style : institution sportive contemporaine, sobre, crédible, aéré, sans effets gadgets.

## Technique
- Astro statique, sans framework JavaScript côté client sauf nécessité réelle.
- Composants réutilisables pour Header, Footer, Hero, Section, Card, CTA et ProgramCard.
- CSS global avec variables de design centralisées.
- Responsive mobile-first.
- HTML sémantique, navigation clavier, contrastes lisibles et attributs alt pertinents.
- Pas de dépendance inutile.
- Le build `npm run build` doit réussir avant tout commit.
- Le déploiement cible est GitHub Pages avec le domaine `https://tennismentorsclub.fr`.

## Contenus prioritaires
- Accueil
- L’association
- Mentorship Access
- Mentorship Talents
- Partenaires
- Contact
- Mentions légales

## Règles éditoriales
- Ne pas inventer de chiffres, de partenaires, de témoignages ou de résultats.
- Présenter TMC comme une association active et structurée, sans exagérer son ancienneté ni son impact.
- Respecter l’anonymat des enfants.
- Utiliser le français partout dans l’interface publique.
