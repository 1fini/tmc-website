# Tennis Mentors Club — site officiel

Site vitrine de Tennis Mentors Club développé avec Astro et publié sur GitHub Pages.

## Développement

Prérequis : Node.js 22.12 ou version ultérieure.

```sh
npm ci
npm run dev
```

Le build de production est généré avec :

```sh
npm run build
```

Le déploiement sur GitHub Pages est automatisé lors d’un push sur `main`. Le domaine public est `https://tennismentorsclub.fr`.

## Logo officiel

Le logo de référence se trouve dans `public/assets/images/tmc-logo.png`. La copie stable destinée aux signatures email est publiée à l’adresse `https://tennismentorsclub.fr/assets/images/tmc-logo-email.png`.
